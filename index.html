Research and open source

When several AI agents correct the same shared state with latency, the loop can oscillate or diverge, the same way a delayed control loop does in a telecom network. I work out exactly when that happens, test it with real LLM agents, and publish tools anyone can verify.

Paper, 2026

Delay-Induced Instability in Multi-Agent LLM Orchestration: Exact Stability Boundaries and a Delay-Aware Extension of UCCF Under peer review

Exact stability boundaries for agent loops with delay, a delay-aware controller, and experiments with real gpt-4o-mini agents inside the loop.

Read the preprint
Paper, 2026

Artificial Intelligence Needs Control Theory: Towards Stable, Adaptive, and Autonomous AI Systems

A closed-loop framework for autonomous AI with formal stability conditions and a reproducible Monte Carlo study.

Open-source tool

loopstab

Predicts from a recorded trace or measured latencies whether an agent loop will converge, oscillate or diverge, and recommends safe settings.

Recovered the delay in 54 of 54 real LLM runs, with no wrong confident verdict. Eleven planted bugs, all caught by its tests.
